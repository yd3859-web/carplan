## 아직 시연 메뉴로 한 번에 안 되는 것
- 이 흐름 전체를 버튼 하나로 자동 재생하는 기능은 없다. 지금 [시뮬레이션 재생]은 S5~S9(출발 → 도착 → 다음 칸)만 돈다.
- 다트·투표·초대·사진·내보내기는 손으로(폰). 플랜의 "시연 메뉴 다시 정하기"에서 장면별 버튼으로 묶을지 팀장과 정한다.
