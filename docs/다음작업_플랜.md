## 할 일: 10장 일정 변경 → 내비 "묻지 말고 바로 바꾸기" (정원 결정 2026-10-31)
지금(Q23·Q24): 안내 중 일행이 칸을 고치면 5초 모은 뒤 "○○님이 서현역을 뺐어요. 경로를 바꿀까요?" → [바꾸기]를 눌러야 내비가 바뀜, [그대로]면 다음 P에서 다시 물음.
문제: 운전 중인 운전자에게 버튼이나 대답을 요구함. 대답이 없으면 계속 옛 경로로 감.

바꿀 방식:
1. 일행이 고침 → 지금처럼 5초 모음(여러 번 고친 걸 한 번으로)
2. 내비 경로를 **자동으로 바꿈** (질문 없음)
3. 음성 + 화면 띠로 알림: "정원님이 서현역을 뺐어요. 경로를 바꿨어요."
4. 화면에 **[원래대로]** 버튼을 10초만 보여 줌 → 누르면 내비만 옛 경로로, 일정은 그대로 두고 폰에 "운전자가 이전 경로 유지"
5. 폰 상태 줄은 "운전자가 보류함" 대신 바로 "차에 반영됨"

같이 정한 것:
| 경우 | 동작 |
|---|---|
| 내비에 들어간 앞 3곳과 상관없는 뒤쪽 칸만 고침 | 경로 그대로, 말도 안 함(폰에만 반영) |
| 다음 목적지 자체가 빠짐·바뀜 | 바로 바꾸고 "다음 목적지가 ○○로 바뀌었어요"로 분명하게 |
| 시간·메모만 고침 | 지금처럼 조용히 반영 |

고칠 곳: 차 `TripNavigator`(`scheduleChangeCheck`·`askChange`·`later`·`pendingChange`/`heldVersion`, P에서 다시 묻기 제거), 차 화면 질문 패널 → 알림 띠 + [원래대로], 폰 상태 줄 문구. 만들 때 `docs/작동시나리오.html` 10장 Q23·Q24 결정과 22장 "✓ 정함"도 같이 고친다.

## 할 일: 12장 출발 전 주유 계획 — Q55 (정원 결정 2026-10-31)
지금(2026-10-31 코드 확인): 모자랄 때만 묻고(안내 중 주행가능거리 < 남은 직선×1.3 + 30km, 아니면 20%/50km), **현재 위치 반경 5km**에서 싼 3곳. 연비·소모량 계산 없음, 계획 단계(폰)엔 주유가 전혀 없음. 문서 12장 "가는 길 최저가"와 코드가 어긋나 있었음(문서에 주의 표시함).

만들 것:
1. 경로: 카카오 길찾기 도로 좌표(`KakaoApi.route`, 시뮬이 이미 씀). 현대 내비는 경로선 좌표 안 줌
2. 소모량: 차의 연료 %·주행가능거리 → "1%당 km" → 남은 일정 거리와 비교, **어디까지 버티는지** 지점 계산
3. 경로 위 주유소: 경로를 따라 약 10km마다 오피넷 반경 5km 조회, 경로에서 가까운 곳만. **출발 전 한 번만, 결과 저장**(API 한도 — `api-quota` 메모)
4. 고르기: 버티는 지점 안쪽에서 최저가, 일정 칸(식사·휴게소) 근처면 우선 → "△△ 지나서 ○○ 주유소(1,620원)에서 넣으면 좋아요"

6. 기존 부족 알림(Q29)은 계획이 없거나 틀어졌을 때만
7. 전기차: 가격 대신 경로 위 충전소(내비 검색)

고칠 곳: 차 `TripNavigator`(`onCarState`·`remainingKm`·`findStation`), shared `OpinetApi`(경로 따라 여러 번 조회) + 계획 계산(새 파일, 테스트), 폰 레일(`TripDayScreen`)에 주유 표시. 1~7의 숫자(10km 간격 등)는 Claude 제안 — 만들 때 확인.
