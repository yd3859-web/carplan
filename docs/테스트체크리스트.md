# 정원이 직접 돌려볼 테스트 체크리스트 (2026-10-30 기준)

"ㅇ" 하나씩 지우면서 보면 된다. 앞은 에뮬에서 Claude가 이미 확인한 것, 뒤는 에뮬에서 못 본 것.
준비: 에뮬 Cold boot → 차 앱 켜기(차주 연결됨 확인) → 폰 앱 켜기. Virtual Console은 `adb forward tcp:8088 tcp:8088` 후 http://127.0.0.1:8088

## A. 폰 캘린더 (2장)
- [ ] 월 보기: 날짜 숫자·요일 색(일 빨강, 토 파랑), 공휴일 이름, 오늘 검정 네모
- [ ] 날짜 누르면 오른쪽(또는 가운데 창)에 그날 동선 레일
- [ ] 일정 추가 → 가운데 창 → 제목만 쓰고 보내기 → 그날에 점 생김
- [ ] 카테고리 칩 → 카테고리 선택 창(흰 카드) → 새 카테고리 + 8색

## B. 여행 (3장)
- [ ] 일정 추가에서 카테고리 "여행" → 날짜 칩으로 2~3일 범위 → 그룹 칩에서 그룹 고르기 → 보내기 → 바로 레일 화면
- [ ] 레일 끝 [+] 또는 [장소 추가] → 장소 이름 쓰고 넣기 → 노드 생김
- [ ] 시간 안 쓴 칸에 회색 "예상 hh:mm" → 누르면 확정(검정)
- [ ] "코멘트 남기기" → 글 쓰고 보내기 → 말풍선 + "나 · 시각"
- [ ] 노드를 길게 눌러 끌어서 순서 바꾸기
- [ ] X로 빼기 → 아래 "내가 △△를 뺐어요 · 되살리기" → 되살리기
- [ ] 월 보기에 여러 날 막대, 그날 동선에 같은 레일 + 최근 코멘트

## C. 차 첫 화면 (7·8장)
- [ ] 상태 줄: 연료·주행가능·기어, 오늘 칸 레일, 이번 주
- [ ] Virtual Console에서 기어 D → "주행 중" 표시, 일정 추가 버튼 막힘

## D. "다음 목적지로 갈까요?" (9장)
- [ ] 차 앱 켤 때 오늘 여행 있으면 검정 띠 질문 + (실차면 소리)
- [ ] [가기] → 내비에 "경유지 2개 포함" 경로 → 폰 레일에 파란 "다음" 노드, 제목 밑 "차에 반영됨 · 다음 도착 hh:mm"
- [ ] [○○ 도착 처리 (시연용)] → 폰 레일 ✓ 회색 + 레일 채워짐, 차도 다음 칸으로
- [ ] 끝까지 도착 → "오늘 일정을 모두 다녀왔어요"(실차 소리), 제목 밑 "다 다녀옴"
- [ ] Virtual Console 기어 P → D → 질문이 다시 뜸

## E. 일정 변경 → 내비 갱신 (10장)
- [ ] 차가 안내 중일 때 폰에서 칸 빼기/넣기 → 5초 뒤 차 띠 "○○님이 △△를 뺐어요. 경로를 바꿀까요?"
- [ ] [바꾸기] → 내비 경로 바뀜, 폰 "차에 반영됨 · 다음 도착" 갱신
- [ ] [그대로] → 폰 빨간 "운전자가 보류함", 같은 변경으론 다시 안 물음
- [ ] 기어 D → P 하면 보류했던 질문 다시 뜸
- [ ] 메모만 고치면(경로 무관) 질문 없이 "차에 반영됨"

## F. 그룹·초대 (4장·7장)
- [ ] 그룹 탭 → 새 그룹 → 그룹 화면(코드 6자리, 초대 링크 보내기, 멤버, 새 여행)
- [ ] `adb shell am start -a android.intent.action.VIEW -d "carplan://i/TEST77" com.htb.carplan.phone` → "그룹 초대" 창 → 참여 → "대학 동기"(민수) 들어감
- [ ] 코드로 참여 칸에 TEST77 → 같은 창
- [ ] 친구 목록에 민수(같은 그룹 이력), 친구 코드 MINSU2로 추가해도 됨
- [ ] 그룹에서 새 여행 → 레일, 제목 밑 그룹 이름, 오른쪽 위 "오늘 이 차로 가요" → "내 차 · 운전자 나"
- [ ] 차 [같이 탄 사람 추가] → 그 그룹 QR + 코드. 오늘 여행이 나만 그룹이면 [새 그룹] → QR
- [ ] 브라우저에서 https://carplan-htb.web.app/i/TEST77 → 코드 표시·앱에서 열기 버튼
