# 팀장이 직접 돌려볼 테스트 체크리스트 (2026-11-02 기준)

[x] = 에뮬에서 Claude가 이미 확인한 것, [ ] = 아직. 각 장 맨 위 **방법** 줄대로 하면 된다.
기능 설명은 `만든것_정리.html`, 명세 원본은 `작동시나리오.html`.

## 0. 테스트하는 방법 (먼저 읽기)

### 0-1. 에뮬레이터 켜기
1. 터미널: `emulator -avd Pleos_Connect_v2_1_0 -no-snapshot-load` (**반드시 Cold boot**. 안 그러면 차 신호가 이상함)
2. 다 켜지면(1~2분) 차 앱 실행: `adb shell am start --user 10 -n com.htb.carplan.car/.MainActivity`
3. 새 빌드 설치: `./gradlew assembleDebug` → `adb install -r --user 10 car-app/build/outputs/apk/debug/car-app-debug.apk` (폰 앱은 `phone-app/...phone-app-debug.apk`)
4. 이미 떠 있는 앱을 앞으로: `adb shell am start --user 10 --activity-single-top -n com.htb.carplan.car/.MainActivity` (옵션 없이 열면 편집 중인 화면이 사라짐)

### 0-2. 차 앱 시연 메뉴 (확인용 버튼 모음)
- 차 화면 왼쪽 위 **"carplan" 글자를 길게 누르기** → 시연 메뉴
- **연료 10/20/50/100% · 연료차로/전기차로**: 주유 기능 시험. 끝나면 **[실제값] 두 개**로 되돌리기
- **[오늘 시험 여행 만들기]**: 판교역 → 율동공원 → 정자역 3칸 여행이 오늘에 생김
- **[시뮬레이션 재생]**: 차가 실제 도로를 따라 움직이는 흉내(기어 D → 이동 → 도착 → P → 문 열기). [일시정지]/[2배속]/[끝]
- **[시험 일행 픽업 등록]**: 가짜 친구 픽업(백현동 카페거리)
- **[지금 출근 일정 만들기]/[시험 출근 지우기]**: 출퇴근 질문 시험
- **[시험 여행 지우기]**: 오늘 "시험 여행"만 지움 — **시험 끝나면 꼭 누르기**(차가 팀장 실제 계정에 연결돼 있어서 실제 캘린더에 남음)
- **[반반 미리보기]/[다크 모드 미리보기]**: 화면 모양 확인

### 0-3. Virtual Console (차 신호 직접 바꾸기)
- `adb forward tcp:8088 tcp:8088` → 브라우저 http://127.0.0.1:8088
- 기어 P/D, 문 열기(BODY), 좌석 착석, 배터리·주행거리를 바꿀 수 있음. **GPS(위치)는 없음** → 이동은 시뮬레이션으로

### 0-4. "친구 폰" 역할 (계정 두 개 필요한 기능: 픽업·초대·코멘트·푸시)
- 같은 에뮬에 깔린 **폰 앱은 차와 다른 계정**이라 친구로 쓸 수 있다
1. 차 앱 [같이 탈 사람] 탭 → [이 여행 QR 띄우기] → 아래 **코드 6자리** 확인
2. `adb shell am start --user 10 -a android.intent.action.VIEW -d "carplan://i/코드" com.htb.carplan.phone` → "그룹 초대" 창 → [참여하기]
3. 폰 앱에서 친구가 할 일(픽업 장소, 칸 빼기 등)을 함
- **한계**: 차가 D단이면 Pleos가 폰 앱 창을 "주행 중에는 사용할 수 없습니다"로 막음 → 시뮬레이션을 [일시정지]하고 Virtual Console에서 기어만 잠깐 **P**로 바꾸면 폰 화면이 보임. 실제로는 폰이 따로라 문제없음
- **제일 확실한 건 실제 폰 두 대**(팀장 폰 = 차주, 다른 폰 = 친구)

### 0-5. 키보드
- 에뮬은 Mac 키보드로 바로 칠 수 있음(**영어만**). 한글은 화면 키보드. `adb shell input -d 0 text "pangyo"`도 됨
- **ESC 키는 누르지 말 것**(대화창이 닫힘)

### 0-6. 끝나고 정리
1. 시연 메뉴 [시험 여행 지우기], 연료 [실제값] 두 개
2. 내비에 길안내가 남아 있으면 내비 화면 [안내 종료]
3. 실제 계정에 생긴 시험 기록(예: 차량 관리 · 주유)은 폰 차량 탭에서 지우기

## 11/2 새로 만든 것

## N1. 차 일정 추가 — 날짜·시간·장소 (8장)
**방법**: 차 [캘린더] 탭 → [이 날 일정 추가]
- [x] [날짜] 버튼(처음엔 오늘) → 가운데 달력 창 → 20일 누르면 버튼이 "11월 20일"로, 지난 날은 회색이라 못 누름
- [ ] 달력 ‹ › 와 옆으로 밀어 달 넘기기
- [x] [시간 정하기] → 시·분 휠 → 위아래로 밀면 가운데 칸에 맞춰 멈춤(진동), 위아래 숫자 누르면 가운데로, 분은 5분 단위 → 칩에 "11:25"
- [x] 장소 칸 누르고 글자 쓰기 → 키보드가 떠도 칸이 안 찌그러지고 글자가 보임, 화면 키보드 빨간 [검색]/Mac Enter로 닫힘
- [ ] [추가] → 캘린더 그날에 일정, 시간·장소 맞는지

## N2. 장소 고르기 — 현대 내비 먼저 (8·3장)
**방법**: N1의 장소 칸, 또는 오늘 탭 [칸 편집] → 오른쪽 "장소 넣기"
- [x] 빈 칸일 때 아래 "현대 내비에 있는 곳"(집·회사·최근 목적지) → 누르면 "위치 확인 · 주소"(파란 글자)
- [x] 이름 쓰고 [내비에서 찾기]/Enter → 현대 내비 검색 화면 → 결과 오른쪽 화살표 → 2초 안에 carplan으로 돌아와 "위치 확인 · 용산구 동자동"
- [ ] 내비에서 고르는 중 [그만] → 기다림 끝
- [x] [목록으로] → carplan 안 카카오 목록 → 고르기
- [ ] 칸 편집에서 [이름만 넣기] → 좌표 없는 칸(출발할 때 내비가 이름으로 찾음)
- [ ] 길안내 중에 [내비에서 찾기] → 고른 뒤 원래 여행 경로로 돌아오는지(내비 화면에서 확인)
- [ ] (실차) 즐겨찾기 집·회사가 실제로 뜨는지 (에뮬은 빈 칸)

## N3. 가는 길 최저가 주유소 (12장)
**방법**: 시연 메뉴 [연료차로] + [20%] → [오늘 시험 여행 만들기] → 닫기
- [x] 레일 위 "주유하기 · 임시" + [최저가 주유소 찾기] → "가는 길 최저가 주유소" 5곳(가격·"율동공원 지나서")
- [x] 하나 고르기 → 레일 "주유 · ○○ · 경유지로 넣었어요", 오른쪽 "다음 ○○주유소 · km · 분 · 도착"
- [x] "주유소가 필요해요" 질문이 다시 안 뜸
- [x] 레일 판교역 시각이 주유소 도착 시각보다 뒤(예: 주유소 15:07 → 판교역 15:25)
- [x] [내비 보기] → 내비에 경유지 2개(주유소, 판교역)
- [ ] 전기차로 바꾸고 같은 흐름 → 근처 충전소 목록(카카오)

## N4. 자동 주유 기록 (15장)
**방법**: 시연 메뉴 [연료차로] + [20%] → 닫기 → 다시 메뉴 [50%] → 닫고 **1분 기다리기** (= 주유소에서 넣은 것)
- [x] 질문 없이 위 알림 줄 "주유 기록 남김 · 4.5L · 8,670원 · 고칠 건 폰 차량 탭에서" + 소리 "주유 기록 남겼어요. 8,670원이에요."
- [x] 오늘 일정에 "차량 관리 · 주유"
- [ ] 폰 차량 탭 주유 기록: 리터·금액·주유소 이름·리터당 가격 메모, 이번 달 주유비에 더해짐
- [ ] 1분 전에 기어 D로(Virtual Console) → 그 순간 기록
- [ ] 전기차로 같은 흐름 → kWh만, 금액 없음
- [ ] (실차) 실제 주유소에서: 탱크 크기가 실제와 맞는지, 그 주유소 가격이 맞는지
- 시험 뒤: 연료 [실제값] → 1분 안에 차 앱 다시 설치하거나 생긴 기록을 폰에서 지우기(100%로 올라가며 기록이 하나 더 생김)

## N5. 픽업 — 친구 폰 지도 (11장)
**방법**: 0-4대로 친구 폰 참여 → 폰 앱 레일 [픽업] → [장소 고르기] → "seohyeon station" → 서현역 → 차 앱으로
- [x] 차 "Jungwon 태우러 가요. 위치를 일행에게 보여 줄까요?" → [네, 출발] → 오른쪽 "Jungwon 태우러 · 서현역"
- [x] "여기로 갈까요?"가 떠 있을 때 친구가 픽업을 넣어도 위 질문으로 바뀜, 길안내 중에 넣어도 한 번 물음
- [x] 시뮬레이션 재생 → [일시정지] → Virtual Console 기어 P → 폰 앱: 파란 **차 모양**(가는 방향), 남은 길 파랑 선, "차가 약 9분 뒤 도착 · 남은 2.3 km", "2.3 km 중 0.0 km 왔어요" 막대
- [x] 끝까지 가면 "2.3 km 중 2.3 km 왔어요", "차가 도착했어요", "차 도착 · 탔으면 눌러 주세요"
- [ ] 중간 지점에서 지나온 길이 회색으로 바뀌는지 (실폰 2대로 보는 게 좋음)
- [ ] **실폰 2대**: 차가 움직이는 동안 친구 폰 지도에서 차 모양이 5초마다 따라오는지, 지도 확대가 자연스러운지
- [ ] [탔어요] → 차 "동승자 1명", 다음 칸으로 / 다 태우면 "픽업 끝 · 위치 공유 껐어요", 지도에서 차 사라짐
- [ ] [공유 없이] → 경로는 가되 폰 지도에 차 없음
- [ ] 두 명 픽업 → "픽업 순서를 총 시간 기준으로 바꿨어요"(직선 추정)
- [ ] (Functions) 친구 폰 푸시 "곧 도착해요 · 약 2분"
