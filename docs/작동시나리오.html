👤 사람 · 차
users/{uid} 이름, 사진, fcmTokens[], soloGroupId, carId?
users/{uid}/categories/{id} 사용자가 추가한 카테고리: 이름, 색 (기본 3개는 앱에 고정)

👥 그룹 · 일정
groups/{gid} 이름, memberIds[], ownerUid, inviteCode, solo(나만 그룹 여부)
groups/{gid}/events/{eid} 캘린더의 모든 일정: 카테고리, 제목, 시작·끝 날짜(시간), 하루종일?, 장소?, 반복?, 알림(몇 분 전)?, 메모, 체크리스트[{글, 완료}], 만든사람, deleted

…/days/{date}/records/{id} 기록 칸: 장소, 연결 stopId?, 계획밖여부, 도착·떠난 시각, 사진 URL[](최대 10), 한 줄 글(note), 만든 주체(차 id). 코멘트는 days/{date}/comments에 stopId = 연결 stopId 또는 record id
groups/{solo}/events/log-{date} 여행 없는 날의 "일상 기록" 일정(자동, 카테고리 다른 일정) — 그 밑에 days/{date}/records
…/records/{id}/comments/{id} uid, 글, 시각
groups/{gid}/darts/{id} 다트 방(6장): 범위(전국/근처/지역), 결과{이름, 좌표}, 던진 횟수, 던진 사람, 연결 eventId?
groups/{gid}/votes/{id} 질문, 후보[], 표{uid:번호}, 상태
여러 날 여행(Q04): 사용자가 날짜를 골라 만든다. 캘린더에는 이어진 여행 하나로 보이고, 날짜를 누르면 그날 일정(장소 칸)이 따로 보인다. 내비 경로도 하루 단위, 차 앱은 오늘 것만 띄움
