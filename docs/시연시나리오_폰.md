# 시연 시나리오 — 폰 앱 편 (2026-11-02)

한 이야기로 앱 기능을 **전부** 한 번씩 쓰는 흐름. 차 쪽은 `시연시나리오_차.md`, **장면 번호(S1~S12)가 같다** — 두 문서를 나란히 보면 된다.
버튼 위치는 `테스트체크리스트.md`, 기능 설명은 `만든것_정리.html`.

## 등장인물·기기
| 인물 | 역할 | 기기 |
|---|---|---|
| 민준 | 차주·운전자 | 차 앱(Pleos) + 폰 앱 ① |
| 서연 | 친구(동승자) | 폰 앱 ② |
| (도윤) | 친구(픽업 받는 사람) | 폰 앱 ③ — 폰이 2대뿐이면 서연이 같이 맡음 |

**에뮬 한 대로 할 때**: 에뮬 안 폰 앱 = 서연(차와 다른 계정). 민준 폰 몫은 차 앱이나 실폰으로. 차가 D단이면 Pleos가 폰 앱 창을 막으니 시뮬 [일시정지] + Virtual Console 기어 P (체크리스트 0-4).

## S0. 준비 (시연 전날)
| 누가 | 할 일 (버튼) | 보이는 것 | 기능 |
|---|---|---|---|
| 민준 | 첫 실행 → [구글로 시작하기] (또는 [나중에 할게요]) | 바로 캘린더 | 1장 로그인 |
| 민준 | [차량] 탭 → 차 화면의 6자리 코드 입력 | "차 연결됨", 상태 줄에 연료·주행가능 | 차 연결(차주) |
| 민준 | [설정] 탭: 이름, 일정 알림 스위치, 주유 알림 기준 20%, 구글 캘린더 같이 보기 | 월 보기에 구글 일정도 | 설정·Q05 |
| 민준 | [차량] 탭 엔진오일 [기록], 보험 [갱신일] | "다음 yyyy-mm-dd · n일 남음", 캘린더에 정비 | 15장 |
| 서연 | 폰 앱 설치·첫 실행 | 캘린더 | |
| 민준 | [같이 탈 사람] 탭 [+] → 친구 추가 → 서연 친구 코드 | 친구 목록에 서연 | 4장 친구 |

## S1. 여행 만들기 → 다트로 어디 갈지 정하기 (출발 3일 전)
| 누가 | 할 일 | 보이는 것 | 기능 |
|---|---|---|---|
| 민준 | 캘린더 토요일 **길게 누르기** → 일정 추가 창 → 카테고리 "여행", 날짜 토~일 2일, 제목 "주말 여행" → 보내기 | 월 보기에 2일짜리 막대, 레일 화면 | 2·3장 |
| 민준 | 레일 화면 [같이 갈 사람] → 서연 한 번 누르기 (+ 도윤은 [QR·링크]로 링크 보내기) | 서연 폰에 초대 → [참여하기]. 이 일정 전용 그룹이 생김 | A안 일정 단위 초대 |
| 도윤 | 링크 https://carplan-htb.web.app/i/코드 누르기 → 앱 열림 → [참여하기] | 같은 여행 레일 | 초대 링크·딥링크 |
| 민준 | 레일 위 [다트 · 동네 뽑기] → 범위 **[내 위치 100km]** (전국·지역도 보여 주기) → 던지기 | 셋 폰에 **동시에** 지도 줌인 → "황남동 · 경주시" | 6장 다트, 실시간 |
| 서연 | 다트 결과 아래 [맛집] | 그 동네 맛집 목록(카카오) | Q57 다트 → 추천 |
