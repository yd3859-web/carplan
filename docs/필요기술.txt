차량용 캘린더 (이름 미정) — 필요 기술 총정리
작성: 2026-10-29
근거: 차량용 캘린더 총정리 1판, 교정지 1·2판 답, Pleos 공식 문서, 카카오·공공데이터 문서

상태 표시
  [된다]   공식 문서에서 확인됨
  [확인]   있을 가능성은 있지만 에뮬레이터·문의로 확인해야 함
  [없다]   공식으로 제공되지 않음
  [직접]   SDK 기능이 아니라 직접 만들어야 함


====================================================================
0. 개발 환경
====================================================================
- 플랫폼: Pleos Connect (Android Automotive OS 기반)
- Android API 28 이상, Gradle 8.0 이상, Java 또는 Kotlin
- Pleos Connect 에뮬레이터 (Android Studio AVD)
- 운전 중 사용: 앱이 주행 제한 상태(CarUxRestrictions)를 확인해 막힌 기능을 줄이거나 꺼야 함.
  주행 중 사용을 선언하지 않은 앱은 대체로 주행 중 사용 불가. 주차 중에는 모든 기능 가능.
- 앱 구성: 차 앱(Pleos) + 폰 앱(동승자·일정 편집) + 서버

====================================================================

7. 에뮬레이터로 먼저 확인할 것 (우선순위 순)
====================================================================
1. 내비 안내 없이 현재 위치가 오는가 (5장 기록, 1장 주유소 판별)
2. 현재 위치·경로 상태·TBT에 들어 있는 필드
   - 남은 시간, 도착 예정 시각, 경로 좌표가 있는가 (3장 경로선, 도착 전 알림)
3. 경유지 3개째를 넣으면 어떻게 되는가 (오류 / 무시)
4. 시동 상태(IGNITION_STATE)가 꺼질 때 앱이 값을 받을 수 있는가
5. 연료량 속성(FUEL_LEVEL 등)이 읽히는가 → 안 되면 기술지원 문의
6. onDestinationArrived / onWayPointArrived가 실제로 오는가, 어떤 값이 오는가
7. 에뮬레이터 결과와 실차가 다를 수 있음
   (문서: 이벤트는 내비 앱의 구현과 상태에 따라 다를 수 있음)

방법: API를 버튼으로 호출하고 들어오는 값을 화면·로그에 그대로 찍는 확인용 앱을 먼저 만든다.

8. 외부 API·서비스 목록
====================================================================
- 카카오 로컬 API: 좌표→주소/행정구역, 키워드 검색, 카테고리 검색(주차장·주유소·카페·음식점·관광명소)
- 카카오맵(또는 다른 지도) SDK: 폰에서 차 위치·경로 표시
- 외부 길찾기 API(필요 시): 픽업 순서 비교, 경로선
- 한국석유공사 오피넷 유가정보 오픈API
- 한국도로공사 주유소별 가격·업체 현황 API (공공데이터포털)
- 서버: 계정, 그룹, 일정 동기화, 위치 중계, 기록·사진 저장, 푸시 알림
  (Firebase 같은 실시간 DB + 푸시로 시작하면 개발량이 줄어든다)
