## 사용 흐름 평가 (2026-10-30 밤, Claude) — 전체 60~65%
| 흐름 | 완성도 | 걸리는 것 |
|---|---|---|
| 처음 시작(설치→로그인→차 연결) | 40% | 첫 실행 안내 없음, 차 연결이 차량 탭 깊숙이, 혼자/여럿 묻는 단계 없음 |
| 여행 짜기(폰) | 70% | 여행 만든 뒤 "장소 넣기" 다음 행동이 약함, 여러 날 사이 이동 불편 |
| 같이 짜기(초대→투표·다트·코멘트) | 60% | 들어온 사람에게 "지금 짜는 중"이 안 보임, 투표·다트가 ⋮ 안에 숨음 |
| 출발(차 타고→안내) | 75% | "오늘 이 차로 가요" 안 누르면 차가 띄울 여행이 헷갈림, 착석 QR은 실차 확인 |
| 가는 중 바꾸기 | 80% | "그대로" 뒤 동승자 폰의 다음 행동이 불분명 |
| 도착→기록 | 55% | 사진 남기기 유도가 푸시뿐(실폰 미확인), 계획 밖 칸 이름이 주소라 손이 감 |
| 돌아보기(일기장→내보내기) | 55% | 내보내기가 레일 ⋮에만, 지난 여행 보는 길이 세 갈래 |
| 평소(출퇴근·차량 관리) | 50% | 출퇴근 제안 시점을 모름, 차량 탭이 "지금 할 일"로 안 이어짐 |

다음 효과 큰 것: ① 첫 실행 3단계 안내 ② 화면마다 "다음 할 일" 한 줄 ③ 하루 보기 역할을 화면 맨 위에 드러내기.
