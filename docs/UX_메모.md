# UX 메모 — 써 보면서 불편한 점 (Claude가 계속 쌓음)

정원 기준 (2026-10-30): **앱 완성도, 특히 UI/UX가 최우선.** 차 화면은 "보여 주는 화면 + 할 일 하나 + 나머지는 주차 중 더보기".
표시: ✅ 고침 · 🔧 고칠 차례 · 💬 정원 의견 필요

## 차 화면
| | 느낀 점 | 제안 |
|---|---|---|
| ✅ | 버튼 8개 + 3단(오늘·이번 주·버튼)이라 컴퓨터 화면 같음 | 레일 크게 + "다음" 한 곳 + [안내 시작] 하나 + [더보기] (2026-10-30 바꿈) |
| ✅ | 팝업이 흰 바탕에 묻힘 | 어두운 배경 + 회색 판 + 테두리 |
| ✅ | 주행 중에도 버튼이 눌림 | 기어 D면 보기 전용 띠 + 터치 막음 |
| 🔧 | 첫 화면 오른쪽 "다음" 아래가 텅 빔 | 다음 칸까지 거리·시간(카카오), 그 칸의 최근 코멘트 한 줄("여기 주차 어려움") |
| 🔧 | 상태 띠 글자가 작음(14~18sp) — 운전 중 흘끗 보기엔 작다 | 띠는 줄이고 숫자 22sp 이상, 단위만 작게 |
| 🔧 | 질문 띠(검정)가 화면 위를 다 덮어 일정 레일이 밀려 내려감 | 질문은 오른쪽 "다음" 패널 자리에 크게 띄우고 레일은 그대로 |
| ✅ | 우리 앱이 그리던 회전 안내·지도가 내비와 겹침 | 뺌. 남은 거리·시간·도착 시각만 글자로 |
| 🔧 | 일정 추가 창이 작고, 키보드가 뜨면 바깥 탭으로 닫혀 버림 | 큰 전체 화면 입력 + 바깥 탭 무시, 시간은 키패드 대신 [지금+1시간] 같은 큰 버튼 |
| 🔧 | 차 다트가 아직 버튼 두 개짜리 | 폰과 같은 전체 화면 다트(주차 중) |
| 🔧 | 시스템이 붙인 메모("투표로 정함", "다트로 정함")가 사람 메모처럼 보임 | 작은 회색 태그로 |
| 🔧 | 에뮬은 처음부터 동승자 4명으로 나옴(좌석 신호 초기값) | 실차 확인 전까진 0명이면 숨김 |
| ✅ | 화면 모양이 하나뿐이었음 | **정원 결정**: 두 모양. 혼자 켜면 넓게(레일 + 다음 + 안내 시작), 내비 옆 반반이면 하루 타임라인이 화면 전부(지난 칸 접기, 버튼은 안내 시작 하나). 조작은 동승자 폰에 맡김. 우리가 그리던 내비 반쪽 화면은 뺌. 시연 메뉴 "반반 미리보기"로 확인 |

## 폰 화면
| | 느낀 점 | 제안 |
|---|---|---|
| ✅ | 다트가 바늘 도는 그림 → 지도 타일 → 점 지도까지 어색했음 | 전체 화면 게임, 시·도 선 지도 → 꽂히면 줌인 |
| ✅ | 다트로 넣은 칸 이름이 "서울특별시 양천구 신월4동"처럼 김 | 칸 이름은 "신월4동", 메모에 "다트 · 양천구" |
| ✅ | 장소 검색 창 열어도 커서가 안 감 | 자동 포커스 |
| 🔧 | 여행 레일 화면 위 버튼줄(픽업·투표·다트·내보내기·오늘 이 차로 가요)이 작은 글자 5개 | 아이콘+글자 큰 칩, 또는 레일 끝 [+] 메뉴로 |
| 🔧 | 레일 칸마다 [코멘트 남기기]·[사진]·[한 줄] 버튼이 반복돼 레일이 길고 산만 | 칸을 누르면 펼쳐지는 방식, 평소엔 말풍선만 |
| 🔧 | 기록 칸이 같은 장소에 계속 쌓임(P단 5분마다) | 30분·300m 안 같은 계획 밖 칸이면 새로 안 만듦 |
| 🔧 | 투표 창이 처음에 "새 투표" 화면부터 열림 | 투표가 있으면 목록부터 |
| 🔧 | 선택 칩이 곳곳에서 Material 보라색 | 검정 채움으로 통일 |
| 🔧 | 캘린더 오늘 헤더 정보가 작은 회색 한 줄에 몰림 | 다음 목적지·시간을 크게, 차 상태는 아이콘으로 |
| 🔧 | 차량 탭 "주기/기록" 버튼이 행마다 반복, 글자 작음 | 항목을 누르면 열리는 상세로 |
| 🔧 | 기록 탭 = **날마다 따로 쓰는 일기장**(정원). 지금은 일정 목록처럼 보여 일기장 느낌이 없음 | 날짜별 카드(대표 사진 + 한 줄 + 들른 곳 수), 오늘 쓰기 버튼 크게, 여행 없는 날도 바로 쓰기 |
| 💬 | 그룹 탭이 그룹 목록 + 코드 참여 + 친구 코드가 한 화면에 다 있음 | 다른 앱 참고안 정원과 정하는 중 |
