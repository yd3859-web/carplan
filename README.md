# carplan

**캘린더에 쓴 일정이 차를 움직이는 차량용 캘린더 앱.**
일행이 폰으로 같이 짠 하루 일정이 그대로 현대 내비의 경유지가 되고, 차를 세울 때마다 그날의 기록이 한 칸씩 쌓여 일기장이 됩니다. 쌓인 기록은 다음 여행 추천으로 이어집니다.

> ### ▶ [기능 안내서 보기 — carplan-htb.web.app/guide](https://carplan-htb.web.app/guide)
> 화면 사진과 함께 전체 기능을 **사용 흐름 순서**(여행 전 → 여행 날 → 다녀와서 → 다음 여행)로 설명합니다. 심사·체험 전에 이 한 장이면 충분합니다.

## 한눈에

| 흐름 | 하는 일 |
|---|---|
| 여행 전 (폰) | 캘린더 한 줄 입력 → 투표·다트·AI 추천으로 어디 갈지 → 레일에 장소 칸(끌기·동선 최소 정렬·근처 추천) → 초대·채팅(자동 카드)·픽업 자리 |
| 여행 날 (차) | "다음 목적지로 갈까요?"(음성+버튼) → 픽업 데리러(그때만 차 위치 공유) → 일행이 폰에서 바꾸면 **달리는 중 경로 자동 반영** → 오늘 갈 길 최저가 주유소·주차장·도착 5분 전 알림 |
| 다녀와서 | P단+문 신호로 **기록 칸 자동 생성**(주차 위치 포함) → 사진·한 줄 → 스크롤 일기장 → 주유·소모품 차계부 자동 |
| 다음 여행 | 기록으로 취향 계산 + 전국 72개 대표 코스(공공데이터) + AI → "다음엔 여기 어때요?" → [이 여행 만들기] 한 번 |

| 모듈 | 어디서 | 내용 |
|---|---|---|
| `car-app` | Pleos Connect (차) | 오늘 레일, 갈까요 질문, 내비 연동, 음성 명령, 기록, 주유·주차, 픽업, QR, 다트, 차량 관리 |
| `phone-app` | 안드로이드 폰 | 캘린더, 여행 레일 편집, 초대·채팅, 투표·다트, 픽업 지도, 기록 일기장, AI 추천, 차량 탭 |
| `shared` | 두 앱 공통 | Firestore 데이터 형식과 경로 |

## APK

| 파일 | 설치할 곳 |
|---|---|
| [`apk/ArCARic_carplan-car_release.apk`](apk/) | Pleos Connect Emulator (또는 Pleos 차) |
| [`apk/ArCARic_carplan-phone_release.apk`](apk/) | 안드로이드 폰 (Android 9 이상) |

두 APK 모두 release 서명 빌드이고 항상 최신 코드 기준으로 올라 있습니다. 서버(Firebase)는 운영 중이라 따로 설정할 것이 없습니다.

## 테스트 환경

| 항목 | 내용 |
|---|---|
| 차 | Pleos Connect Emulator **v2.1.0** (AVD `Pleos_Connect_v2_1_0`, Android 14 / API 34 Automotive, arm64), **Cold boot** 권장 |
| 차 화면 규격 | **2560 × 1440 px, 160 dpi** (가로). 내비와 반반(창 폭 1100dp 미만)일 때는 좁은 모양으로 바뀜 |
| 폰 | Android 9 (API 28) 이상. 구글 로그인·푸시·사진은 Google Play 서비스가 있는 실제 폰에서 |
| 서버 | Firebase (Auth, Firestore, Storage, Cloud Functions, Hosting) — 운영 중 |
| 외부 API | 카카오 로컬·모빌리티, 오피넷, 한국관광공사 TourAPI(추천 코스), Claude(추천 — 서버에서만) — 키가 없어도 대체 동작 |
| 필요한 권한 | 폰: 알림, 위치(다트·픽업), 사진. 차: Pleos Vehicle·내비·음성 권한(설치 시 자동) |

## 실행 방법

### 1. 설치
```bash
# 차: Pleos Connect Emulator를 Cold boot로 켠 뒤
adb install -r apk/ArCARic_carplan-car_release.apk
# 폰: USB 디버깅을 켠 폰을 연결한 뒤 (또는 APK 파일을 폰에서 열어 설치)
adb install -r apk/ArCARic_carplan-phone_release.apk
```
에뮬레이터 하나로 같이 볼 때는 폰 앱을 에뮬레이터에 함께 설치해도 됩니다(앱마다 계정이 따로 생깁니다).

### 2. 처음 켜기 (5분 체험)
차와 폰이 **시연 계정**으로 미리 연결되어 있어, 11월 한 달치 일정·기록·친구가 채워진 상태로 바로 볼 수 있습니다.

1. **차 앱**: 처음 켜면 자동으로 시연 계정의 차가 됩니다 (6자리 코드 입력 없음)
2. **폰 앱**: 첫 화면에서 **[시연 계정으로 시작]** → 차와 같은 계정으로 들어갑니다
   - 내 계정으로 새로 시작하려면 [나중에 할게요] → 차 화면 시연 메뉴 [차주 연결 풀기] → 차에 뜬 6자리 코드를 폰 차량 탭에 입력
3. 폰 캘린더에서 날짜를 눌러 여행을 만들고 장소 칸을 넣으면, 차 "오늘"과 내비 경로에 바로 반영됩니다
4. 차 화면 **왼쪽 위 "carplan"를 길게 누르면 시연 메뉴** → [오늘 여행 만들기] → [주행 재생]: 실제 주행 없이 타기 → 주행 → 도착 → 기록까지 자동 재생
5. 폰 기록 탭에서 다녀온 날이 일기장으로 쌓인 것과, 맨 아래 "다음엔 여기 어때요?" → [이 여행 만들기]

### 3. 차 화면 시연 메뉴 (실제 주행 없이 확인)
위에서부터 순서대로 누르면 하루가 흘러갑니다. 차나 다른 사람이 하는 일만 버튼으로 대신합니다.

| 버튼 | 하는 일 |
|---|---|
| 11월 다시 채우기 | 지난 여행·기록·사진·친구·앞으로의 여행이 있는 11월로 다시 채움 |
| 오늘 여행 만들기 | 주말 친구들과 분당 4곳 하루 (다시 누르면 처음 상태로) |
| 일행 탑승 | 조수석·뒷좌석 착석 → "같이 타셨나요?" QR |
| 주행 재생 | D → 실제 도로 따라 이동 → 도착 → P → 문 열고 내림, 도착마다 기록 칸 |
| 민지가 칸 넣기 | 친구 계정이 폰에서 칸을 넣음 → 달리는 중 차 경로가 바뀜 |
| 일행 코멘트·채팅 / 지훈이 투표 열기 | 친구 계정의 코멘트·채팅, 투표 |
| 픽업 부탁 | 친구가 태워 달라고 함 → 차가 먼저 들름, 폰 지도에 오는 차 |
| 연료 15% / 전기차로·연료차로 | 주유·충전 질문, 오늘 갈 길 최저가 목록 |
| 출근 상황 만들기 | "회사로 갈까요?" |
| 반반 보기 · 밤 모드 | 내비와 나란히, 밤 화면 |

Virtual Console(기어·문·좌석 직접 조작): `adb forward tcp:8088 tcp:8088` 후 http://127.0.0.1:8088

### 4. 소스에서 빌드할 때
1. Android Studio(AGP 9, JDK 17)로 이 저장소를 엽니다.
2. `car-app/google-services.json`, `phone-app/google-services.json`을 넣습니다(보안상 저장소에 없음 — 필요하면 팀에 요청).
3. `local.properties`에 `KAKAO_REST_KEY=`, `OPINET_KEY=` (없어도 빌드·실행됨, 대체 동작). 시연 계정 버튼은 `DEMO_PASSWORD`가 있을 때만 보입니다(제출 APK에는 들어 있음).
4. `./gradlew assembleDebug` → 차·폰에 설치. release 빌드는 저장소 밖 서명 키와 `keystore.properties`가 필요합니다.
