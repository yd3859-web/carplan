# carplan

**캘린더에 쓴 일정이 차를 움직이는 차량용 캘린더 앱.**
일행이 폰으로 같이 짠 하루 일정이 그대로 현대 내비의 경유지가 되고, 차를 세울 때마다 그날의 기록이 한 칸씩 쌓여 일기장이 됩니다.

| 앱 | 어디서 | 하는 일 |
|---|---|---|
| `car-app` | Pleos Connect (차) | 오늘 일정 레일, "다음 목적지로 갈까요?"(음성 + 버튼) → 내비 경유지, 일정이 바뀌면 경로 자동 반영, P단에 세우면 기록 칸, 주유·충전 계획, 픽업, 동승자 QR, 차량 관리, 주차 중엔 캘린더·기록·다트까지 |
| `phone-app` | 안드로이드 폰 | 캘린더, 여행 하루 레일 편집(장소 검색·순서·시간·코멘트), 같이 갈 사람 초대, 여행별 채팅, 투표·다트, 픽업 지도, 기록 일기장(사진·한 줄·움직이는 지도), 차량 관리 |
| `shared` | 두 앱 공통 | Firestore 데이터 형식과 경로 |

## APK
| 파일 | 설치할 곳 |
|---|---|
| [`apk/`](apk/) 폴더의 차 앱 release APK | Pleos Connect Emulator (또는 Pleos 차) |
| [`apk/`](apk/) 폴더의 폰 앱 release APK | 안드로이드 폰 (Android 9 이상) |

두 APK 모두 release 서명 빌드입니다. 서버(Firebase)는 이미 운영 중이라 따로 설정할 것이 없습니다.

## 테스트 환경
| 항목 | 내용 |
|---|---|
| 차 | Pleos Connect Emulator v2.1.0 (AVD `Pleos_Connect_v2_1_0`, Android Automotive), **Cold boot** 권장 |
| 폰 | Android 9 (API 28) 이상. 구글 로그인·푸시·사진은 Google Play 서비스가 있는 실제 폰에서 |
| 서버 | Firebase (Auth 익명·구글, Firestore, Storage, Cloud Functions, Hosting) — 운영 중 |
| 외부 API | 카카오 로컬·모빌리티(장소 검색·길찾기), 오피넷(주유소 가격) — APK에 포함, 없으면 내비 검색·직선거리로 대체 |
| 필요한 권한 | 폰: 알림, 위치(다트 "내 위치", 픽업), 사진. 차: Pleos Vehicle·내비·음성 권한(설치 시 자동) |

## 실행 방법
### 1. 설치
```bash
# 차: Pleos Connect Emulator를 Cold boot로 켠 뒤
adb install -r <차 앱 APK>
# 폰: USB 디버깅을 켠 폰을 연결한 뒤 (또는 APK 파일을 폰에서 열어 설치)
adb install -r <폰 앱 APK>
```
에뮬레이터 하나로 같이 볼 때는 폰 앱을 에뮬레이터에 함께 설치해도 됩니다(앱마다 계정이 따로 생깁니다).

### 2. 처음 켜기
1. **폰 앱**: 이름을 넣고 시작(구글 로그인 또는 나중에).
2. **차 앱**: 화면에 뜨는 **6자리 코드**를 폰 앱 첫 화면 또는 [차량] 탭에 입력하면 그 차의 차주가 됩니다.
3. 폰 캘린더에서 날짜를 길게 눌러 여행을 만들고 장소 칸을 넣으면, 차 화면 "오늘"과 내비 경로에 바로 반영됩니다.

### 3. 차 화면 시연 메뉴 (실제 주행 없이 확인)
차 화면 **왼쪽 위 "carplan"을 길게 누르면** 시연 메뉴가 열립니다.
| 버튼 | 하는 일 |
|---|---|
| 오늘 시험 여행 만들기 | 판교역 → 율동공원 → 정자역 하루 일정 |
| 시뮬레이션 재생 | 타기 → D → 실제 도로 따라 이동 → P → 문 열고 내림 (Virtual Console로 기어·문·속도를 보냄), 도착마다 기록 칸 |
| 시험 일행 픽업 등록 | 픽업 받을 사람 → 차가 먼저 태우러 감, 폰 지도에 오는 차 |
| 오래 쓴 것처럼 채우기 | 친구·묶음·지난 여행·기록·주유 기록 등 두 달치 데이터 |
| 연료 10~100% / 연료차·전기차 | 주유·충전 질문 확인 |
| 반반 미리보기 · 다크 모드 미리보기 | 내비와 나란히, 밤 화면 |
| 시험 여행 지우기 · 데모 지우기 | 만든 시험 데이터 정리 |

Virtual Console(기어·문·좌석): `adb forward tcp:8088 tcp:8088` 후 http://127.0.0.1:8088

### 4. 소스에서 빌드할 때
1. Android Studio(AGP 9, JDK 17)로 이 저장소를 엽니다.
2. `car-app/google-services.json`, `phone-app/google-services.json`을 넣습니다(보안상 저장소에 없음 — 필요하면 팀에 요청).
3. `local.properties`에 `KAKAO_REST_KEY=`, `OPINET_KEY=` (없어도 빌드·실행됨, 대체 동작).
4. `./gradlew assembleDebug` → 차·폰에 설치. release 빌드는 저장소 밖 서명 키와 `keystore.properties`가 필요합니다.
